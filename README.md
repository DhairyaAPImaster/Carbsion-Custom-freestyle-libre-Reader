# *Carbsion*

<img src="blob:chrome-untrusted://media-app/8a90fc65-bd6d-4d4b-b92b-9632831275cb" alt="Carbsion Banner.png"/>




**So yeah Carbsion is basically a mostly custom Reader for the freestyle libre sensor (it should work well with libre 1 but not so much with libre 3 as there is open source decryption for libre 1 but not so much for libre 3 even though it is underway). It uses the same decryption software as used by X-drip to decrypt sensor data.**
